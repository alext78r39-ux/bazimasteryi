# 簡介

- bazi.py 八字排盤，能比常用的排盤更清晰地顯示沖、合、刑等關係，計算五行分數，附加《三命通會》等命理評判
- luohou.py 計算羅喉日時,用於提示風水師何時慎用羅盤。
- shengxiao.py 用戶生肖合婚等。








不建議選擇大陸解放後的書籍精讀，貧道有精選紙質和電子書，輔以閱讀輔導，隨緣會友。
