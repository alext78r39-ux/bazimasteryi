# 簡介

- bazi.py 八字排盤，能比常用的排盤更清晰地顯示沖、合、刑等關係，計算五行分數，附加《三命通會》等命理評判
- bazi.py -b 直接輸入四柱，已經知道年月日時干支時可直接排盤，不必先換算日期
- convert.py 干支轉換小工具

（原本的 luohou.py 六爻與 shengxiao.py 生肖合婚已移除。）

# 安裝
- 安裝依賴庫

```python
pip install bidict lunar_python colorama
pip install matplotlib     # 只有「大運流年圖表」分頁需要
pip install sxtwl          # 選用，只有「可能出生時間」提示需要
```

- linux打開終端或windows打開cmd或git的bash或powercmd等工具

進入到代碼所在目錄。


# 圖形介面／單一 EXE

不想裝 Python？可以直接下載 `BaziMaster.exe`，雙擊即開啟圖形介面，
不需要安裝 Python，也不需要安裝任何依賴庫。

下載後的使用方式：

| 操作 | 說明 |
| --- | --- |
| 雙擊 `BaziMaster.exe` | 開啟圖形介面（主控台視窗會自動隱藏） |
| `BaziMaster.exe 1977 8 11 19 -n` | 直接排盤，結果輸出到畫面 |
| `BaziMaster.exe -b 丁巳 己酉 癸未 壬戌` | 直接輸入四柱排盤 |
| `BaziMaster.exe --cli` | 命令列互動選單 |
| `BaziMaster.exe --show-console` | 開圖形介面但保留主控台視窗（除錯用） |
| `BaziMaster.exe --chart-selftest` | 不開圖形介面，驗證圖表能否產生 PNG |
| `BaziMaster.exe --reset-settings` | 不開圖形介面，把介面設定還原成預設值 |

圖形介面分成六個分頁：

1. **八字排盤** — 填出生年月日與時辰，勾選公曆／閏月／女命，按「排盤」
2. **直接輸入八字** — 已經知道四柱時直接排盤
3. **大運流年圖表** — 把大運與流年畫成三種走勢圖，可另存 PNG
4. **盲派暗局做功** — 依盲派暗局體系排出做功、病藥、格局與歲運應期
5. **命令列模式** — 直接貼 `bazi.py` 的引數
6. **管理員設定** — 調整介面外觀，設定會被記住

## 大運流年圖表

「大運流年圖表」分頁沿用「八字排盤」的出生資料，按「畫　圖」後可切換三種圖：

| 圖表 | 內容 |
| --- | --- |
| 五行分數走勢 | 把大運與流年干支都加回命盤，沿年份畫金、木、水、火、土五條線，附總分平均線 |
| 身強弱數值走勢 | 每年的「比劫梟印」分數總和，以**本命值**為參考線 |
| 大運干支走勢 | 每步大運的天干十神與地支長生分兩軸畫，橫軸標干支與年齡 |

- 計分沿用 `bazi.py` 自己的表與權重，所以**圖上的數字與文字排盤一致**。
- 每個年份的分數 = 本命四柱 ＋ 該年大運干支 ＋ 該流年干支，總分恆為 86。
- 切換上方的圖表種類會直接重畫，不必再按「畫　圖」。
- 三張圖的橫軸都有淡色虛線標出每步大運的起點，方便對照。
- 按「另存 PNG…」可把圖存成檔案。
- 大運年份來自 `lunar_python` 的起運時間，因此**只能用出生日期畫**；
  「直接輸入八字」沒有出生日期，算不出西元年份，按「畫　圖」會提示改用出生日期。
- 圖表功能需要 `matplotlib`（未安裝時只有這個分頁會提示缺套件，其餘分頁照常運作）：

```python
pip install matplotlib
BaziMaster.exe --chart-selftest      # 不開圖形介面，直接驗證能否畫出 PNG
```

## 盲派暗局做功

「盲派暗局做功」分頁與命令列 `mangpai.py` 走同一套程式，輸出《盲派八字暗局做功體系》V2.0 的七步判讀：

1. 明局做功 — 分體用、列十神力（透／根／藏）、五類做功、四種病
2. 尋藥 — 以七殺解伏吟與合絆，走解神鏈
3. 察飛神 — 拱飛、合飛、沖飛、三合三會拱夾的伏神與三宮
4. 定格局 — 有病有藥／有弱藥／藥反噬／無藥，並給格局層次
5. 類象 — 干支、十神、宮位與做功類象（勾「不印類象」可略過）
6. 歲運 — 大運流年如何引動暗局
7. 綜斷 — 格局斷語與提要

- 兩種輸入擇一：**四柱**（`以四柱分析`）或**出生日期**（`以日期分析`）。
- 四柱模式沒有出生日期，算不出起運年份，所以**只列大運干支、不列流年**；
  「只看某年」因此只對日期模式有效，四柱模式會提示改用日期。
- 勾「不印類象」只留理法與歲運。
- 地支六合的解藥在原始體系中尚未列表，程式會標示「待擴充」而不臆造。

```bash
python mangpai.py 1977 8 11 19 -n            # 農曆，女命
python mangpai.py -g 1977 9 23 19 -n         # 公曆
python mangpai.py -r 2023 -2 1 10            # 閏月（只對農曆有意義）
python mangpai.py -b 丁巳 己酉 癸未 壬戌    # 直接輸入四柱
python mangpai.py 1977 8 11 19 -n --年 2030  # 只看某一年的應期
python mangpai.py 1977 8 11 19 -n --不印類象 # 省略第五步類象
```

## 管理員設定

在「管理員設定」分頁（選單「功能 → 管理員設定」也可進入）可以調整：

| 項目 | 說明 |
| --- | --- |
| 佈景主題 | Windows 內建的 `vista` / `clam` / `default` 等 |
| 介面字體／字級 | 按鈕、輸入框等控制項的外觀 |
| 輸出字體／字級 | 排盤結果文字的等寬字體與大小 |
| 自動換行 | 輸出超過視窗寬度時折行；取消則改用捲軸 |
| 背景／文字顏色 | 可用色塊選擇，也可用「自訂…」開小視窗挑色 |
| 視窗大小 | 記住上次視窗的寬高 |

- **設定會即時套用**：改完直接切到「八字排盤」分頁就能看到效果，不必重開。
- **按「套用並儲存」才會寫檔**，否則關掉視窗就沒了。
- 設定存放在 `%APPDATA%\BaziMaster\settings.json`，是純文字 JSON，可直接備份或用記事本修改。
- 「還原預設值」會把設定檔覆蓋回預設並立刻套用。
- 設定檔損壞時，程式會自動忽略它並載入預設值，不會開不起來。

```python
BaziMaster.exe --reset-settings      # 不開圖形介面，直接把設定還原成預設值
```

> **輸出字體請用等寬字型**
> 排盤靠全形空格與固定 15 字元欄寬對齊，換成明體以外的比例字型，
> 表格欄位會跑掉。預設的 `NSimSun`（新細明體）可以正常對齊。

> **關於 sxtwl（選用）**
> `sxtwl` 是 C extension，在 **Python 3.13 沒有預先編譯的 wheel，原始碼也編譯失敗**，
> 因此這個版本的 EXE 沒有內含它。
> 它現在**只影響「直接輸入八字」底下的「可能出生時間」反推提示**，
> 沒有它四柱排盤一樣完整，只有那幾行提示不會出現。
> 想連提示一起看，可改用 Python 3.11 建立環境後執行 `pip install sxtwl`，
> 再重新打包即可（`bazimaster.spec` 會自動偵測並把 sxtwl 一起打包）。

自行從原始碼打包：

```python
pip install pyinstaller
python build_exe.py
```

產物為 `dist\BaziMaster.exe`（單一檔案，約 45 MB；含 matplotlib 是圖表分頁的代價）。


# 使用

- 直接輸入八字

```python
$ python bazi.py -b 丁巳 己酉 癸未 壬戌
```

四柱之間用空白分隔，每柱兩個字（天干＋地支）。

天干與地支必須陰陽相配（甲己配子未、乙庚配丑申之類），
配錯時程式會直接提示錯誤，不會默默排出錯誤的命盤。
`bazi.py -b` 會額外反推「可能出生時間」，這段需要 `sxtwl`；
沒有安裝 `sxtwl` 時只是少這一段提示，其餘排盤完全正常。


- 八字排盤
